# BetBot MX

Bot de análisis de apuestas deportivas con banca ficticia: fútbol (Champions, Premier, LaLiga, Liga MX, Serie A, Ligue 1), NFL, NBA, MLB, LMB, tenis y eSports (LoL, Valorant, CS2).

- Interfaz estilo iOS 27, en español.
- Modelos de probabilidad, valor esperado y Kelly fraccionado.
- Oportunidades de Oro y analista IA (Claude) con búsqueda en internet.
- Boleto con recomendación de casa de apuestas.
- Acceso desde el celular y actualizaciones con un clic.

**Instalación:** descarga el repositorio (Code → Download ZIP), descomprímelo y abre `iniciar.bat`. Guía completa en [LEEME.md](LEEME.md).

> Herramienta de análisis y práctica con dinero ficticio. No apuesta dinero real. Juego responsable.
